# Smart Waste Collection System

System analysis and design for campus waste collection scheduling and recycling rewards.

## Project owner
Moaaz Beder manages this individual project and handles analysis, modeling, database design, UI mockups and documentation.

## Project board
[Trello board](https://trello.com/b/IrAXKHVf/campus-recycling-rewards-system-analysis)

## Structure
- docs/01-planning/: project identification, System Request, methodology and work plan.
- docs/02-feasibility/: feasibility study and economic analysis.
- docs/03-requirements/: gathering evidence and requirements specification.
- diagrams/dfd/: As-Is/To-Be DFD, data dictionary and process specifications.
- diagrams/uml/: use case, activity, sequence and class diagrams.
- database/: ERD, normalization and relational schema.
- ui/: three manual UI mockups.
- submission/: reviewed final report and submission evidence.

The existing Word draft and Excel feasibility workbook are preserved in their corresponding documentation folders.

## Working and review rules
1. Choose a task from To Do and move it to In Progress.
2. Complete its checklist and save the deliverable in the relevant folder.
3. Record a meaningful Git commit and link the artifact in Trello.
4. Move the card to Review and check it against the section materials.
5. Verify names, requirements, role permissions and rules across DFD, UML, ERD and UI.
6. Correct findings, then move the card to Done.

This is an individual project: Review is a self-review step. Keep only one or two active tasks at a time. Review the board weekly and update progress after each work session. Intermediate dates will follow the confirmed course schedule.

Final documentation deadline in the supplied lab agenda: 30 December 2026.
